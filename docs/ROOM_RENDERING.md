# iOS 房间画质与家具资产

用户在「设置 › 画面 › 画质」切换。所选档位存在本机 `UserDefaults` 的
`room.renderQuality`，测试库使用独立命名空间。手动档即时生效。
自动档按报告物理内存选择低（低于 5 GiB）、中（5 到 7 GiB）、高（7 GiB 起）。
当系统热状态达到 serious 或 critical，自动档在这次启动内降一档。
切档沿用房间对象、家具摆位和猫的当前状态。

## 三档参数

| 项目 | 低 | 中 | 高 |
| --- | --- | --- | --- |
| 每点最多渲染像素 | 1.5× | 1.75× | 3× |
| 太阳投影 | 关 | 开 | 开 |
| 家具自遮挡 | 开 | 开 | 开 |
| 家具对地板的软接触影 | 关 | 关 | 开 |
| 环境光全景 | 256 × 128，原柔光环境 | 256 × 128，原柔光环境 | 512 × 256，线性 HDR 三柔光区 |
| 鎏金／江南／樱庭三把样板的原稿底色 | 调色板 | 最长边 128 px | 原尺寸 192 或 256 px |
| 家具粗糙度和法线 | 每槽粗糙度常量，网格法线 | 每槽粗糙度常量，网格法线 | 120 件网格家具的 520 个槽、照片板及收纳箱使用配套材质图 |
| 内置猫模型 | 低档按需资源，未就绪用中档 | 内置中档 | 有高档用高档，否则用内置中档 |

渲染倍率由屏幕原生倍率封顶。设置实例集中在
[`RenderQuality.swift`](../ios/MeowverseCore/Sources/MeowverseCore/RenderQuality.swift)。
房间和摆放编辑器读取同一档。明信片使用独立印刷画布和最高可用材质，在冻结的房间布局上生成软影。
款式预览使用完整材质和 HDR 柔光。桌面 AR 使用其原生渲染配置、原尺寸底色和家具自遮挡。地板软影、HDR 和表面贴图由室内高档控制。
HDR 指线性高动态范围环境光纹理，屏幕色调处理沿用 SDR 房间管线。

## 网格与摆放

- 120 件批准的 v2 网格共 586,614 三角面，每件 2,062–7,940 面。三档共用同一份位置、索引、
  平滑法线、UV0、材质槽和猫的互动点。另有代码绘制的墙挂照片板。
- 导出尺度为 3 Blender 单位／格。App 从各款的默认占地和包围盒算基准比例。
  每侧留 0.08 格，摆位缩小时按两轴较紧的一侧缩小，扩大占地时按基准比例居中。
  每格位置以 15 × 15 房间中心为原点，`turn` 为绕 Y 轴的四分之一圈。
- 目录定义、几何哈希、部件、许可、交互校验和 Blender 修改流程见
  [家具技术规范](../art/furniture/TECH_SPEC.md)。老存档 ID 通过目录别名使用对应的 v2 网格和遮挡。
  墙挂照片板和收纳箱由运行时程序绘制。
- 网格以表面和部件维持原外观。材质细节槽从 UV0 派生切线与副切线，顶点增加 24 字节切线数据。调色板纹样及底色沿用 UV0，自遮挡使用独立 UV1。

| 样板 | 默认占地 | 三角面 | 保留原样板强度的槽 |
| --- | ---: | ---: | --- |
| 鎏金沙发 `mv-sofa-e` | 4 × 3 格 | 7,876 | `primary-fabric`、`accent`、`metal` |
| 江南沙发 `mv-sofa-f` | 4 × 3 格 | 7,460 | `wood` |
| 樱庭沙发 `mv-sofa-g` | 4 × 3 格 | 3,524 | `wood` |

## 自遮挡、地板与环境光

| 资源 | 计算参数 | App 使用方式 |
| --- | --- | --- |
| 家具自遮挡 | 每顶点 48 条余弦半球射线，半径 1.65 格，距离二次衰减，最低可见度 0.22 | 每顶点 1 字节，UV1 插值并从共享的 256 × 1 线性纹理取样，写入 PBR 遮挡槽 |
| 地板软影 | 每像素 56 条余弦半球射线，半径 2.9 格，离地 0.004 格探测，距离指数 1.45，最高遮挡 0.68 | 120 件各自以 24 px／格存入 2048 × 2446 灰度图集。按位置、旋转和大小合成 384 × 384 房间图并绑定地板 PBR 遮挡槽 |
| 高档 HDR | 512 × 256 线性浮点等距矩形图。三块柔光由下表定义 | RealityKit 环境光资源，原有日夜曝光和房间色调曲线继续处理不同光相 |

沙发脚、桌腿和开放式底座下的光线遮挡来自模型实际几何。地板每次更新先取消旧任务，按现有
房间布局离主线程合成。旋转、改尺寸、搬动、收纳和删除都会改变布局。提起家具编辑时移除该件地板影，
落定后重新计算。贴图只在布局或功能状态变化时重算。家具跨出房间的部分裁在地板边界，重叠处可见度
相乘，最低为 82／255。地板影采用环境遮挡，太阳仍负责方向投影。挂球属于活动部件，地板预烘焙排除挂球。
桌面 AR 和程序绘制的墙挂照片板使用各自的接地策略。

HDR 坐标使用 App 的 +Y 向上轴，颜色为线性辐亮度。代码将方向归一化，亮区内半径为外半径的 60%。

| 柔光区 | 方向 | 外半径 | 线性 RGB |
| --- | --- | ---: | --- |
| 主柔光 | (−3, 6, −4) | 22° | (4.0, 3.6, 3.1) |
| 冷补光 | (4, 3, −2) | 24° | (1.3, 1.55, 1.9) |
| 轮廓光 | (−2, 5, 4) | 16° | (5.0, 4.5, 3.9) |

## 材质贴图

高档使用 20 对项目自制材质图。最初评审的木、绒布和金属为 512 × 512，其余为 256 × 256。
粗糙度是线性灰度，法线是切线空间 RGB。纹理带 mipmap，线性过滤和 4× 各向异性。
不同家具共用同名材质图，高档按房间实际使用的材质加载。切到低或中后，家具有相同的底色、
花纹和模型，材质槽恢复为已有常量粗糙度与几何法线。

[材质分配表](../art/furniture/surface-maps/bindings.json)定义常用槽、纹样、经评审的样板覆盖及程序绘制家具。
导入流程逐个读取批准网格中的三角面组，任何缺失的材质槽都会阻止资产打包。520 个唯一槽对应 530 个网格部件。
此前没有独立调色板外观的 5 个部件，沿用网格底色和 0.72 默认粗糙度。27 个旧存档别名跟随新目录款式。
墙挂照片板的木框、软木、纸面和图钉也有材质，加上收纳箱的木、金属和珐琅。

| 材质 | 高档表面处理 |
| --- | --- |
| 木材 | 常规木槽用顺纹起伏。原有木纹图案使用同一纹样的凹凸和局部粗糙度 |
| 绒布、普通织物、绳索 | 分别使用绒面、经纬纹、编织股线。格纹、条纹和圆点沿用原图案与周期 |
| 针织 | 使用原纹样的针脚深度。90° 的两处布局使用旋转校正的切线空间法线 |
| 金属、陶瓷、石质颗粒 | 细拉丝、薄釉或颗粒起伏。保留已有金属度与清漆属性 |
| 镜面、水面、蜡和深色内壁 | 镜面和内壁采用低幅细节。水面使用静态小波纹，陶粒、砂和猫粮用颗粒处理 |

带纹样的底色、粗糙度和法线共用原有 UV0 变换，三种纹理的重复周期一致。
木纹、针织和水磨石材质从原有纹样遮罩派生高度，保证颜色纹理与反光变化在同一位置。
自遮挡继续使用 UV1。常规槽以材质图的参考粗糙度校准纹理倍率，保留各配色的原有粗糙度差异。
以下五个槽保留既有样板的纹理强度。

| 槽 | 低／中常量粗糙度 | 金属度 | 高档粗糙度图名／倍率 | 法线 |
| --- | ---: | ---: | --- | --- |
| `mv-sofa-e/primary-fabric` | 0.84 | 0 | `velvet`／1.0 | 绒布细纹 |
| `mv-sofa-e/accent` | 0.23 | 0.12 | `metal`／0.8 | 细拉丝 |
| `mv-sofa-e/metal` | 0.30 | 0.52 | `metal`／1.0 | 细拉丝 |
| `mv-sofa-f/wood` | 0.48 | 0 | `wood`／1.0 | 木纹 |
| `mv-sofa-g/wood` | 0.63 | 0 | `wood`／1.0 | 木纹 |

其他槽的底色、金属度、清漆与绒光参数来自
[`looks.json`](../art/furniture/export/looks.json)。样板的原稿底色出自原 Blender 交付稿，
其索引和哈希在 [`material-maps/index.json`](../art/furniture/material-maps/index.json)。

## 资源量与重烘焙

材质图由 120 件网格家具、照片板与收纳箱共享。40 张贴图在 Release 包中的实际文件字节约
3.84 MB。底色图、家具自遮挡和地板影另占约 1.39 MB。高档按实际材质加载纹理，普通切档保留网格缓存。
地板图集与索引约
0.66 MB，粗糙度与法线图约 1.80 MB。合计约 3.2 MB，按 Release 包中实际文件字节计算。
地板图集在高档首次使用时解码，CPU 灰度数组约 4.8 MiB。房间合成图 384 × 384，
高档地板增加一次材质纹理采样。

在仓库根目录执行。几何、UV 或默认占地变化后，按家具工作台的审查流程更新对应的模型。
重烘焙会写源资源与索引。iOS 烘焙随后验证网格与元数据哈希、槽、尺寸与贴图一致性，
并生成 App 包内副本和 `art-provenance.json`。改动木纹、针织或水磨石源图后需重新生成共享材质图。不用在 App 资源目录手改生成文件。

```sh
blender -b --factory-startup --python-exit-code 1 --python art/furniture/blender/export/bake_occlusion.py
blender -b --factory-startup --python-exit-code 1 --python art/furniture/blender/export/bake_floor_shadows.py
uv run --no-project --with numpy --with pillow python art/furniture/blender/export/bake_surface_maps.py
node scripts/ios/bake-ios-assets.mjs
node scripts/ios/bake-ios-assets.mjs --check
node scripts/ios/furniture-media.mjs
node scripts/ios/furniture-media.mjs --check
node --test scripts/ios/mv-furniture.test.mjs scripts/ios/mv-furniture-details.test.mjs
swift test --package-path ios/MeowverseCore --filter 'FurnitureFloorShadowTests|RenderQualityTests'
python3 ios/check-localization.py
```

`RenderQualityUITests` 从正常入口摆放家具，检查即时切档时解析出的倍率、太阳投影、HDR 环境、
地板影和材质绑定数。测试覆盖旋转保存后的高档重新绑定，Core 另对旋转方向、移动、缩放、裁边和叠加
做数值校验。用于真机对比的命令缓冲耗时、固定布局原型和测试限制见
[材质实测记录](../art/MATERIAL_QUALITY.md)。持续功耗、多人多猫的重场景、低内存机型与完整系统代际的
性能需单独采样。

全库 RealityKit 验收在 iPhone 17 Pro 模拟器 iOS 26.4 完成。共渲染 120 件网格家具、墙挂照片板和
收纳箱，563 个渲染部件逐件验证粗糙度和法线图。关闭材质图后检查绑定全部解除，目录件使用同一网格，
程序件核对几何缓冲。16 件代表家具同机位独立关闭材质图，便于比较花纹、编织纹、镜面、水面和纸面。
